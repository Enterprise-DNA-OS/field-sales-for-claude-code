description: Everything that wants a decision this week, in one list: promotions wrong in store, credits waiting, orders that never reached the ERP, overdue calls, outlets gone quiet, empty shelves.
---

1. `npm run field -- attention [--rep=]`.
2. Present it in the order the command returns, because that order is severity, not date:
   - **Promotion wrong in store.** A compliance problem first, a sales problem second.
   - **Credit waiting on authorisation.** Someone is waiting on a person, not a process.
   - **Order not in the ERP.** Money written and not delivered.
   - **Call overdue.** Coverage.
   - **Outlet gone quiet.** Ninety days with no order from an active account.
   - **Out of stock on shelf.** Every empty facing found and not yet seen full.
3. For each group, give the count, the worst example by days, and one next command. Do not list forty rows. Five lines and an offer to expand.
4. Anything over thirty days old gets named individually. That is not a backlog, it is a thing that has been forgotten.
5. End with the single item you would do first and why.
